The last text a dying phone sends at one percent: a farewell to its charger, a noble death by buffering, a claim of being at 100 percent in spirit — and then the message itself dies mid-sentence, cut off before it can finish saying goodbye a second time. Running the program drops that line into the make.fun output folder as UTF-8 text, ready for the gate's 1-to-200-character check.

## Run it

```sh
python3 main.py
```
